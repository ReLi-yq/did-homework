# 稳健性检验：T1 处理变量的测量方式

## 检验目的
"是否数字化"用 0/1 可能太粗，检验结论是否依赖处理变量的测度：改用**连续数字化强度**。

## Prompt（四要素）
```text
【目标】用 data/raw/digital_transformation_firm_panel.csv 重跑主回归，
将处理变量替换为连续数字化强度：处理组企业按其 managerial_capability 标准化构造强度，对照组为 0。
回归 log_tfp ~ digital_intensity + capital_intensity + 企业FE + 年份FE，聚类到企业。
【边界】合成数据演示；只读 data/。
【验证】输出应包含强度系数、SE、p 值；解释"强度每增加一单位对 TFP 的边际效应"。
【汇报】汇报系数、SE、p 值、边际含义、你的观察。
```

## 结果摘要
- 数字化强度系数：**0.0477**，SE = 0.0082，p = 7.3e-09（高度显著）

## 我的观察
- 强度每增加 1 个标准差，log TFP 提高约 0.048，**显著为正** → "数字化强度越大、效应越大" ✅
- 处理变量用连续强度替代 0/1 后，结论方向一致、显著，不依赖"是否数字化"的粗糙测度。
