# 稳健性检验：R2 安慰剂检验

## 检验目的
排除"估计结果由随机噪声/偶然性驱动"的可能：若随机构造伪处理组也能得到类似效应，则真实估计不可信。

## Prompt（四要素）
```text
【目标】用 data/raw/digital_transformation_firm_panel.csv 做安慰剂检验：
随机抽取与处理组数量相同的"伪处理组"（保留处理时间 2020 不变），重复 200 次，
估计伪 DID 系数分布，报告均值、标准差与 95% 分位区间；与真实估计（0.1209）对比。
【边界】合成数据演示；只读 data/；固定随机种子以保证可复现。
【验证】输出应包含伪估计分布统计；若伪估计均值远离 0 或接近真实值，需警示。
【汇报】汇报伪估计均值/区间、真实估计位置、你的观察。
```

## 结果摘要
- 伪处理组估计：均值 = 0.00008，标准差 = 0.0074
- 95% 区间：[-0.0116, 0.0115]（包含 0）
- 真实估计：0.1209（远在区间之外）

## 我的观察
- 伪估计集中在 0 附近，真实估计 0.1209 远超随机分布 → **结果非随机噪音** ✅
- 只有真实的"数字化转型处理"才产生显著效应，安慰剂通过。
