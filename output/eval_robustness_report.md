# DID 稳健性综合评估报告

> 由综合评估 Agent（eval-did-robustness）依据 S1–S6 流程生成。

## 1. 主结果

- DID 系数（digital）：**0.1209**（企业聚类标准误 0.0047，t=25.6，p<0.001，N=3240）
- 设定：log_tfp ~ digital + capital_intensity + 企业FE + 年份FE，聚类到企业
- 与课堂 Stata 主结果（0.1209, SE 0.0047）**完全一致**（已复现并修复课堂脚本 SE NaN 问题）

## 2. 稳健性判定表

| 检验 | 判定 | 依据 |
|:---|:---|:---|
| R1 平行趋势 | 通过 | 处理前联合 F=0.49, p=0.69（不显著），处理前系数平坦 |
| R2 安慰剂 | 通过 | 伪估计均值≈0.00008，95% 区间含 0，真实 0.1209 远离 |
| R3 替换结果变量 | 通过 | log 劳动生产率系数 0.1205，p<1e-116 |
| R4 改变控制变量 | 通过 | 三设定系数 0.1208–0.1209 稳定 |
| R5 改变聚类层级 | 通过 | industry/province/二维均显著（最保守二维 t≈4.9） |
| R6 极端值处理 | 通过 | winsorize 后 0.1170，p<1e-110 |
| R7 样本调整 | 通过 | 剔行业/规模 0.120–0.121；短窗口 0.0815（动态累积） |
| T1 连续处理强度 | 通过 | 强度系数 0.0477 显著（强度越大效应越大） |
| T2 异质性 | 通过 | 行业/所有制/规模各组均显著为正，差异不大 |
| T3 机制（互补性） | **警示（负发现）** | digital×mc 交互 p=0.53 不显著，不支持能力互补 |

## 3. 结论稳定性

- 主效应 digital ≈ 0.121 在 **R1–R7 全部设定**及 **T1、T2、T4** 下方向一致、显著性保持 → **结论稳健**。
- 系数量级稳定在 0.12 附近（0.117–0.124），仅短窗口（0.0815）与最严格 FE（SE 变大）出现变化，均不改变方向与基本显著性。
- **区分**：以上是"合成数据中的稳健相关"而非"真实因果效应"。

## 4. 残余威胁

- 平行趋势只是**识别诊断而非证明**：p=0.69 支持，但不能排除更微妙的时间趋势差异。
- **T5 识别变弱**：处理时间统一（2020）+ 多维固定效应吸收处理内变异，最严格设定下统计推断力度有限。
- **T3 机制不支持**：未发现"能力互补"机制，机制路径仍不清楚。
- 测量误差、溢出/一般均衡、样本选择在合成数据中未被设计，但仍属理论上的残余威胁。
- 合成数据本身：所有"效应"由 DGP 生成，不能外推到真实企业。

## 5. 主题解读

- 数字化转型对 TFP 的正效应在绝大多数设定下**稳健**，支持"数字化提升生产率"的总体结论。
- **异质性相对有限**（T2）：行业、所有制、规模各组效应接近，未呈现强烈的"某类企业独享收益"。
- **机制未获支持**（T3）：交互项不显著，说明该合成数据中数字化收益不随管理能力递增；
  论文中不宜宣称"高能力企业从数字化获益更多"的互补机制。
- 短窗口效应较小（R7③），提示效应随时间**动态累积**（转型后逐年放大）。

## 6. 对论文写作的建议

- **能说**："数字化转型与 TFP 呈显著正相关（0.121，聚类 SE 0.005）""该发现在多种稳健性设定下保持"
  "处理组在转型后 TFP 显著提升""平行趋势检验支持识别前提"。
- **不能说**："数字化转型因果地提高了 TFP"（应区分统计相关与因果）；"高能力企业从数字化获益更多"
  （T3 不支持）；"效应对所有企业同质"（T2 有细微差异，应如实描述）。
- **需谨慎措辞**：T5 最严格设定下识别变弱，应如实说明"在同时控制行业与地区-年份冲击时，
  由于处理时点统一，识别主要依赖有限变异，推断力度受限"。
- **合成数据边界声明必须保留**：所有结果仅服务于方法演示，不构成真实证据。

## 边界声明

- 本评估基于**合成数据**（DGP 生成），所有结论不能解释为真实企业数字化转型的因果证据。
- 未虚构任何文献；判定均有数值依据；研究者对最终结论负责。
